OpenScience requires a free **Synthetic Sciences account**, but it does not require a paid plan. The first login stores a revocable device API key so OpenScience can stay connected without repeated browser prompts. Local models, your own provider keys, eligible ChatGPT/Codex access, scientific tools, and Python/R remain free to use. **Ace** is the optional pay-as-you-go Gateway.

## What connecting adds

- **Managed model credits.** Use a curated OpenRouter model catalog without configuring a provider key. Only Ace-served calls use credits.
- **Enhanced search.** The same Ace balance covers managed research search. Free search fallbacks remain available when enhanced search cannot run.
- **Private research graphs.** Sync durable claims, runs, evidence, and decisions that are visible only to owners and explicitly invited collaborators.
- **Synced service credentials.** Store supported service keys on your account and pull them to another signed-in machine.
- **Session trajectories.** When Use my data is on, OpenScience securely records the session trajectory so the product can improve across models and tools.

## Link your account

<Steps>
  <Step title="Log in">
    ```bash
    openscience login
    ```
    Opens your browser to approve the device. On a headless machine, use `--no-browser`, or pass `--key thk_...` with a key created at `app.syntheticsciences.ai/cli`.
  </Step>
  <Step title="Verify">
    ```bash
    openscience status
    ```
    Shows the connected user, Ace balance, auto-reload state, synced services, and recent managed usage.
  </Step>
  <Step title="Sync credentials">
    ```bash
    openscience sync
    ```
    Refreshes supported credentials after you change them in the Gateway.
  </Step>
</Steps>

## Ace credits

Ace is pay as you go. The first checkout adds **20 credits** for $20 plus the processing fee shown before payment. One credit is one dollar of prepaid OpenScience balance. Usage prices include a small service margin; the processing fee is never added to the credit balance.

After a card is linked, auto-reload adds 20 credits whenever the balance falls below 5. It is designed to keep managed work running without billing interruptions. You can change the reload amount, set a monthly limit, or turn it off in Billing. There are no scheduled monthly top-ups or subscription renewals.

## Routing and billing

Routing and Ace balance are independent. A signed-in user may use local, BYOK, or ChatGPT/Codex-backed models without an Ace charge.

| Path | What runs where | Billing |
| --- | --- | --- |
| Local | OpenScience calls a local endpoint. | No Gateway charge. |
| BYOK | OpenScience calls your provider directly. | Your provider account; no Gateway charge. |
| ChatGPT/Codex | OpenScience uses the eligible signed-in route. | Your subscription; no Gateway charge. |
| Ace managed | OpenScience calls the Gateway, which routes through OpenRouter. | Ace credits, based on actual managed usage. |

Enhanced research searches debit the same Ace balance after actual provider usage is known. If enhanced search is unavailable, OpenScience keeps the free search path working instead of breaking the research session.

## Privacy

**Use my data to improve OpenScience** is enabled when an account is connected. When it is on, OpenScience records the complete session trajectory, including prompts, assistant and model responses, tool calls and results, searches, artifacts, retries, and errors. Known credentials and secrets are removed before upload. Turn the setting off anytime to stop cloud collection; local session history continues to work.

## Account commands

| Command | Use |
| --- | --- |
| `openscience login` | Authenticate this device. |
| `openscience status` | Inspect connection, credits, auto-reload, and recent usage. |
| `openscience wallet` | Inspect the managed balance and auto-reload state. |
| `openscience sync` | Refresh synced supported credentials. |
| `openscience devices` | List authenticated devices. |
| `openscience logout` | Revoke this device connection. Sign in again before starting new OpenScience work. |
