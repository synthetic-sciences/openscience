OpenScience brings research conversations, code execution, scientific data, and saved results into one project. Start with a question, a file, a paper, or an existing codebase. The agent can investigate, propose a method, carry out the work with available tools, and leave files you can inspect and reuse.

Use this map to find the relevant workflow. Availability depends on your model's capabilities, installed software, connected accounts, and the controls you choose.

## Research and discover

| Capability | Typical input | What you can ask for |
| --- | --- | --- |
| [Literature review](/openscience/literature-review) | Research question, papers, inclusion criteria | A cited comparison, evidence table, search record, and unresolved questions. |
| [Research search](/openscience/research-search) | Query, date range, source or domain restrictions | Web, academic-web, news, or developer results with source links. |
| [Scientific databases](/openscience/database-workflows) | Database query or accession | Structured records and supported sequence, structure, or molecular files. |
| [Read documents](/openscience/documents) | PDF, Markdown, HTML, or text | Summaries, comparisons, extracted tables, and source locations to check. |
| [Explore code](/openscience/code) | Project folder, repository, or error | A code map, explanation, implementation, or tested repair. |

## Analyze and experiment

| Capability | Typical input | Deliverables |
| --- | --- | --- |
| [Data analysis](/openscience/data-analysis) | Dataset and data dictionary | Cleaning code, diagnostics, analysis tables, and a methods note. |
| [Statistics](/openscience/statistics) | Study design, observations, units | Assumption checks, effect estimates, uncertainty, and sensitivity analysis. |
| [Python and R](/openscience/python-r) | Code or an analysis request | Executed calculations, inline plots, files, and repeatable scripts. |
| [Machine learning](/openscience/machine-learning) | Dataset, target, split, evaluation plan | Baselines, metrics, model artifacts, and an experiment comparison. |
| [Genomics](/openscience/genomics) | Sequences, reads, variants, annotations, or single-cell data | Quality checks, derived tables, visual inspection, and reproducible analysis. |
| [Molecular research](/openscience/molecular-research) | Molecules, structures, sequences, or assay data | Descriptors, structural views, or supported predictions and simulations. |
| [Reproduction](/openscience/reproduction) | Paper, code, data, and target result | A bounded reproduction, comparison with the claim, and a record of differences. |
| [Compute jobs](/openscience/jobs) | Command, resources, inputs, and expected outputs | Local or connected remote execution with status and delivered files. |

Use [Experiment plans and evidence](/openscience/experiment-tracking) to define checks, preserve a plan before trials, compare observed outcomes, and retain supported lessons.

## Inspect and communicate

| Capability | What it provides |
| --- | --- |
| [Table explorer](/openscience/tables) | Search, sorting, column schema, missing-value summaries, distributions, and filtered export. |
| [Scientific viewers](/openscience/scientific-viewers) | Molecules, structures, sequences, alignments, genomic summaries, and supported scientific datasets. |
| [Figures](/openscience/figures) | Plots from data with editable source, captions, and publication checks. |
| [Image generation](/openscience/image-generation) | New illustrations or edits to an existing image when image access is configured. |
| [Writing](/openscience/writing) | Reports, manuscripts, methods, citations, and supporting documents. |
| [Saved Results](/openscience/results) | Retained copies of selected outputs, previews, downloads, rename, and recovery from Trash. |

## Organize substantial work

Use [projects](/openscience/projects) to group source folders and deliverables. Use [sessions](/openscience/sessions) for separate questions within a project. [Planning and goals](/openscience/planning) turn a broad objective into checkpoints and reviewable outputs; [context and handoffs](/openscience/context) help continue longer investigations.

Research effort, delegation, independence, and action approval are separate [controls](/openscience/agents). A request to compare methods can benefit from additional investigation; a simple file conversion usually needs a short, focused run.

## Make it your workbench

- Choose [Ace](/openscience/ace), [personal provider access](/openscience/models), or [local models](/openscience/local-models).
- Enable or install [skills](/openscience/skills), inspect the [full skill directory](/openscience/skill-library), and check [scientific tool availability](/openscience/tool-catalog).
- Connect services with [credentials](/openscience/service-credentials) and [MCP connectors](/openscience/connectors).
- Save [project instructions](/openscience/instructions), [custom commands](/openscience/slash-commands), and [configuration](/openscience/configuration).
- Integrate through the [CLI](/openscience/commands), [SDK and local API](/openscience/api), [plugins](/openscience/extensions), or [custom tools](/openscience/custom-tools).

## Try a complete workflow

```text
Use data/measurements.csv and methods/protocol.md. First inspect the data
and propose an analysis. After we agree on the method, save a reproducible
script, a comparison table, a figure, and a short report in results/.
Explain missing inputs and failed checks. Ask before using paid compute.
```

The [workflow cookbook](/openscience/workflow-examples) contains ready-to-adapt requests. If you already have material in hand, choose a starting point from [Source and file types](/openscience/source-types).
