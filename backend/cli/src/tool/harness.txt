Operate a benchmark-bound optimization search. This tool is available only as a control surface over a harness contract created by the benchmark adapter; it cannot create or change that contract.

For hard scientific tasks, use `coalition_start` once to select and persist a contract-bound execution topology. The policy only adds coordination when the inferred decomposability, uncertainty, novelty, tool intensity, and verification risk justify its overhead. It can select a direct solution, centralized review, bounded fork/join, pairwise tournament, or an evolutionary generate-cluster-reflect-rank loop. After every restart use `coalition_status`. For each returned `ready` unit, call the Task tool with exactly its `agent` and a prompt containing its `prompt` plus the bounded upstream `context`. Use a fresh child session for every unit and run no more than `maxWorkers` concurrently. Report the child session and observable artifacts with `coalition_complete`; report actual execution failure with `coalition_fail`. Do not reuse a producer session for verification. Coalition outputs are provisional and never count as benchmark evidence, even when a verification role accepts them.

Use `start` once to open the persisted candidate graph with the contract's budget. Use `status` after restarts and before proposing work. Follow its recommendation: an empty `parentIDs` list opens an independent exploration root; `exploit` refines the verified best; `fuse` combines two verified branches; and `diverge` keeps the best parent but changes the search strategy or paradigm, not just parameters. Use `propose` to register a concrete content-addressed artifact and its verified-parent lineage. Use `observe` for provisional feedback only: observations are explicitly unverified and can never become the best candidate, authorize descendants, or enter retrospective memory. Official verification is intentionally not an action in this tool; only the bound external evaluator can promote a candidate. Use `hindsight` to retrieve bounded evaluator-linked successes and failures for this exact benchmark task.

Keep the direct ReAct path for ordinary tasks. Do not start a candidate search without an optimize contract, a metric, and a finite contract budget.
