Run a shell command in the session workspace; set `workdir` instead of changing directories in the command.

Use Bash for builds, tests, package managers, Git, utilities, and scripts. Use dedicated file tools for reading, searching, creating, or editing files; do not write through shell redirection, `echo`, or `cat` when a file tool fits.

Quote paths containing spaces. `command` is required and `timeout` is optional. Output beyond ${maxLines} lines or ${maxBytes} bytes is saved automatically; do not add `head` or `tail` only to limit output. Describe each call in 5–10 words.

Issue independent calls together. Join dependent commands with `&&` only when later work must stop after failure.

Git and GitHub safety:
- Commit, push, or create a pull request only when explicitly requested.
- Before committing, inspect status, diff, and recent log; stage only intended paths.
- Never change Git config, bypass hooks, force-push, use interactive Git, or destructively reset/checkout without explicit authorization.
- Never amend a pushed commit or push directly to `main`/`master`.
- For a requested PR, inspect the full branch diff, use `gh`, create at most one, and return its URL.
