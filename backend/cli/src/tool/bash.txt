Run a shell command in the session workspace. Set `workdir` instead of changing directories in the command.

Use Bash for builds, tests, packages, Git, utilities, and scripts. Prefer file tools for reading, searching, creating, or editing files; do not write through shell redirection when a file tool fits.

Use research_search or webfetch for internet retrieval, not curl or wget. Use `compute_job` action `wait` for detached compute instead of shell polling or sleep.

Quote paths containing spaces. Output beyond ${maxLines} lines or ${maxBytes} bytes is saved automatically. Run independent calls together; join dependent commands only when later work must stop after failure.

Commit, push, or open one PR only when requested. Inspect status and diff, stage only intended paths, never bypass hooks or force-push, and never amend a pushed commit or push directly to `main`/`master`.
